# Distribution légère pour GitHub — rc7

La base de ce dépôt provient de l’archive légère rc7 vérifiée. Les sources
d’application, tests et licences d’origine sont conservés ; les ajouts
de présentation, l’exemple Cast3M et les copies expurgées sont documentés
dans la [provenance publique](docs/provenance/README.md).
Trois petits modèles nécessaires aux tests de partage sont conservés.
Les volumineux maillages, journaux intermédiaires et corpus de vérification
sont fournis séparément dans `Mailleur_rc7_verifie_2026-11-07.zip` (SHA256
`d1a1bcc758242c0c858b4c7456790cd4125a0ec7574c18acdac2acaaab3eac1f`).

Les rapports résumés gardés ici peuvent référencer des preuves brutes absentes
de cette distribution légère : consulter l'archive complète pour les examiner.
Ne pas présenter l'absence de ces données comme une nouvelle exécution de test.
Le manifeste d’origine est conservé comme référence historique ; le contenu
public final doit être décrit par son propre manifeste. Voir aussi
l’[erratum de publication](ERRATUM_PUBLICATION.md).

Pour publier sur GitHub, extraire ce dossier puis suivre README.md et
CONTRIBUTING.md. Le projet n'a pas été envoyé à GitHub automatiquement.
Python, ses dépendances et les outils Rust ne sont pas inclus.
